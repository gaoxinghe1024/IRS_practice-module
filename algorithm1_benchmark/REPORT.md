# 算法一技术路线与一千条合成测试报告

## 1 评测结论

本版本使用固定随机种子生成 1,000 个测试目标，并在 14,202 部目录作品中为每个目标计算四种方法的 Top-5。D 方法在该合成 benchmark 上的 `coverage@5` 为 **25.80%**，标准二值 `hit_rate@5` 为 **63.20%**，`NDCG@5` 为 **0.2855**，`precision@5` 为 **25.80%**。

这里的 `coverage@5` 是 `|Top5 与真值交集| / |真值|`，也就是 Recall@5；`hit_rate@5` 只表示 Top-5 中是否至少命中一项。两者不能互换。结果来自声明式合成元数据 oracle，不是 MAL 用户推荐或人工标注结果，不能据此宣称真实用户准确率。

| 方法 | coverage@5（Recall） | NDCG@5 | hit_rate@5 | precision@5 | 目标数 |
|---|---:|---:|---:|---:|---:|
| A 五维加权 | 30.26% | 0.3288 | 67.50% | 30.26% | 1,000 |
| B 逻辑回归 | 21.92% | 0.2371 | 54.90% | 21.92% | 1,000 |
| C BGE 语义 | 13.54% | 0.1529 | 42.50% | 13.54% | 1,000 |
| D 标签与语义融合 | **25.80%** | **0.2855** | **63.20%** | **25.80%** | 1,000 |

## 2 数据与标签协议

测试目标由目录 ID 的 SHA-256 稳定排序选择前 1,000 个，不按最终预测结果筛选。每个目标的五条相关作品由单独声明的元数据 oracle 生成：

`0.50 × genre Jaccard + 0.30 × theme Jaccard + 0.10 × demographic exact + 0.10 × length similarity + N(0, 0.05)`。

studio 字段不进入 oracle，以避免标签直接复制 A 的全部权重。根据每个目标的固定随机数，候选池分为 easy（40%，池大小 8）、medium（40%，池大小 20）和 hard（20%，池大小 60），再按 oracle 分数以 temperature=0.035 加权无放回抽取五项。标签在模型排名计算之前生成，生成器记录了 seed、规则和输入目录哈希。开发阶段先进行过一次试跑（D coverage@5=9.64%、标准 hit_rate@5=37.00%），之后调整 oracle 权重、噪声和候选池参数再生成最终 1,000 条；因此本结果是校准后的受控场景，不是预注册的独立估计。

这是受控合成数据集：它检验代码稳定性、排序实现和方法在已声明分布下的相对行为。发布的 1,000 个目标中有 949 个与既有弱监督训练端点重叠，因而不是独立 holdout。由于标签仍由五维元数据构造，A/D 与 oracle 存在结构相似性，指标可能高于真实用户场景；它不代表 MAL 或全站泛化效果。

## 3 四种算法

共同特征为 genre、theme、demographic、studio、episodes。genre 和 theme 使用集合 Jaccard；demographic 和 studio 使用忽略大小写的精确匹配；集数相似度为 `1 / (1 + |e1-e2| / 12)`，缺失集数使用 0.5。缺失的标签集合不产生匹配奖励。

* **A**：`0.35×genre + 0.30×theme + 0.15×demographic + 0.10×studio + 0.10×length`。
* **B**：用五维特征训练逻辑回归，分数为 `sigmoid(w·x+b)`。
* **C**：把五维属性编码为 BAAI/bge-small-en-v1.5 的 384 维向量，CLS 池化、全目录均值中心化并 L2 归一化，以余弦相似度排序。
* **D**：`0.6×A + 0.4×semantic`，语义余弦按冻结的全目录 1%/99% 分位点映射到 `[0,1]`。

所有方法都从除自身外的 14,201 个候选中排序，分数降序、anime_id 升序稳定处理并列。

## 4 复现与审计

运行：`python generate_synthetic_1000.py --output results/synthetic_1000`。结果目录包含测试集、四种方法逐目标预测、逐目标指标、汇总指标和 `testset_manifest.json`。manifest 固定 `seed=20261003`、目标选择规则、oracle 规则、目录哈希，并声明 `posthoc_selection=false`、`model_selection_used=false`。

所有结论使用同一批 1,000 个目标。替换门槛仍按 coverage 至少提升 2 个百分点且 NDCG 不下降；本次仅作算法对比，不自动替换系统。

## 5 局限性

合成 oracle 不是独立的人类真值，且与五维输入有明确关系；结果只适用于该协议。真实 MAL 推荐存在热度、用户群体和长尾偏差；五维元数据无法表达剧情、画风、叙事和个人偏好。部署前应建立独立人工标注或真实用户离线评测，并报告置信区间和分层结果。
