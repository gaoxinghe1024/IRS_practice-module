## 3. 切分、留一、规则场景、候选与泄漏控制

- 用户级切分 70 / 15 / 15，`split_seed = 42`，按偏好集合规模分层；主组（集合 ≥ 6，即可见历史 ≥ 5）与稀疏组（2–5）分开报告。完整切分：main / test 3,000，main / train 14,000，main / val 3,000，sparse / test 600，sparse / train 2,800，sparse / val 600。
- 本级别使用 24,000 个用户（嵌套在完整切分中：True）。分区用户交集：{'train&val': 0, 'train&test': 0, 'val&test': 0}。
- Query：验证 / 测试每个用户 1 个隐藏目标，训练每个用户最多 3 个目标；共 56,676 个 query（{'main': {'test': 3000, 'train': 42000, 'val': 3000}, 'sparse': {'test': 600, 'train': 7476, 'val': 600}}）。隐藏目标从不进入画像输入 H。
- 训练样本：每个训练 query 1 个正例 + 4 个弱负例（同一候选集合内确定性采样，`negative_seed = 42`，排除该用户全部已知正例），共 265,380 对（训练 247,380 对；验证用户的 18,000 对只用于早停的 logloss），负例不足 0 次。B0 / B1 / C0 共用同一组样本。
- 规则场景：R0 无筛选；R1 关键词 = H 中最常见的 genre（同频按名称），关键词对 genre 或标题做 AND 子串匹配；R2 公开评分 ≥ 7.0 且集数 ≤ 26（未知集数不满足）；R3 = R1 + R2。全部是严格模式：目标不满足规则时不插回，记为 target_not_eligible，单独报告端到端结果。
- 候选：对通过规则的**完整目录**排序（不采样候选），排除 H 本身。同分按 MAL id 升序决定名次；AUC 对同分给 0.5，不受 id 排序影响；候选数 < 2 时 AUC 为 null。
- 主指标（预注册）：R0、主组、候选数 > 8、目标 eligible 的用户级 Macro HR@8；NDCG@8、MRR@8、AUC 同表报告。

## 4. 五组实验的实现、参数与预算

- **A0** = rating_norm + 0.15 × hits（hits = 候选的 genre/theme 标签落在 H 的 top-10 命名空间标签中的个数）。
- **A1**：在验证集比较 hits 权重 [0.05, 0.1, 0.15, 0.2, 0.3]，选中 **0.05**（验证 HR@8 0.0267）；选中值是预注册网格的最小值，说明数据可能偏好网格以外的权重，但网格没有在看到结果后扩展。
- **B0**：LightGBM 原生 `lgb.train`（objective = binary，按原始分数排序），特征 rating_norm, hits；10 个预先生成的确定性 trial（网格 {'num_leaves': [15, 31], 'max_depth': [5, 8], 'learning_rate': [0.03, 0.05], 'min_child_samples': [50, 100], 'reg_lambda': [1.0, 5.0]}），上限 500 棵树、早停 50 轮（验证对 logloss），按完整候选验证 HR@8 选中 trial 0：{'learning_rate': 0.05, 'max_depth': 8, 'min_child_samples': 100, 'num_leaves': 31, 'reg_lambda': 5.0}（验证 HR@8 0.0573）。
- **B1**：LightGBM 原生 `lgb.train`（objective = binary，按原始分数排序），特征 rating_norm, hits, genre_affinity, theme_affinity, demographic_affinity, studio_affinity, length_affinity, max_tag_similarity；10 个预先生成的确定性 trial（网格 {'num_leaves': [15, 31], 'max_depth': [5, 8], 'learning_rate': [0.03, 0.05], 'min_child_samples': [50, 100], 'reg_lambda': [1.0, 5.0]}），上限 500 棵树、早停 50 轮（验证对 logloss），按完整候选验证 HR@8 选中 trial 0：{'learning_rate': 0.05, 'max_depth': 8, 'min_child_samples': 100, 'num_leaves': 31, 'reg_lambda': 5.0}（验证 HR@8 0.1320）。
- **C0**：PyTorch 内容双塔，两侧隐藏层 [128, 64]，输入为 genre / theme / demographic / studio（出现 ≥ 5 次的制作公司，其余归入 UNK）多热向量与数值特征及缺失 mask（番剧塔 378 维，收藏塔 380 维），点积 logits + BCEWithLogitsLoss，不使用 in-batch 负例；10 个 trial，选中 trial 0：{'dropout': 0.0, 'learning_rate': 0.0003, 'out_dim': 64, 'weight_decay': 1e-05}（验证 HR@8 0.1053），最多 30 轮、patience 3，设备 CPU。
- 最终配置用训练 seed [42, 2026, 7] 各训练一次（共 9 个模型，见 models_manifest.json）。说明：预注册的 LightGBM 网格没有 bagging / feature_fraction 子采样，seed 只通过分箱抽样起作用；训练对有 247,380 条，超过 LightGBM 直方图分箱的抽样上限 200,000（bin_construct_sample_cnt），seed 决定参与分箱的行，因此三个 seed 的分箱边界和树略有不同（已在模型文件中核对：B0 不同，B1 不同）；seed 间差异只反映这一来源的随机性。
- 调参成本（B0 10 个 trial, B1 10 个 trial, C0 10 个 trial，合计）：B0 拟合 52 s + 完整候选验证评分 2,056 s；B1 拟合 53 s + 完整候选验证评分 2,447 s；C0 拟合 380 s（验证评分未单独计时）。完整目录的验证评分是主要开销。
- 比较关系：B0 是两特征的控制组；B1 与 C0 使用同源元数据但特征表示不同，C0 vs B1 不是“同输入只换模型”。
- B1 特征重要性（gain 占比，部署 seed）：rating_norm 65.9%，studio_affinity 11.0%，hits 6.5%，length_affinity 5.2%，max_tag_similarity 4.2%，demographic_affinity 2.9%，theme_affinity 2.6%，genre_affinity 1.7%。重要性不是因果贡献，特征的作用以 B1 − B0 的对照为准。

## 7. 失败案例与限制

`case_analysis.md` 给出 13 个真实测试案例：A0 命中、学习模型（B1 与 C0）未命中 26；学习模型命中、A0 未命中 518；五个核心模型都未命中 2399；稀疏收藏（可见历史 1–4 部） 600；混合偏好（genre 熵高于验证集中位数） 1809；规则排除了隐藏目标（严格模式不插入） 5146；严格空结果（候选数 = 0） 0；候选不足 8 个 0（测试中出现次数）。

主要限制：
- 代理标签：评分 ≥ 8 的集合不等于收藏夹；未评分条目是弱负例，AUC 衡量的是目标相对这些弱负例的区分度。
- 静态快照（2023）与用户留出：评估的是“同一时期内其他高评分条目能否被找回”，不是对未来行为的预测。
- 流行度偏差：目标多为热门高分番剧，依赖公开评分 / 人气的特征天然占优；冷门目标普遍难以进入前 8。
- 字段覆盖：theme 与 demographic 依赖补充文件且覆盖不完整，缺失按 NaN / 空集合处理，没有补造。
- LightGBM 的 seed 只影响分箱抽样（网格无子采样），三个 seed 的差异不代表完整的训练随机性。
- C0 理论上能编码没有交互的新番，但本次没有 item-disjoint 实验，不能声称新番冷启动更好。
- 时延在单台笔记本上测得，只用于相对比较，不代表生产环境。
